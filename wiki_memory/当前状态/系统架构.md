# 系统架构

[app.py](../../srttools/app.py) 创建 QApplication 与主窗口。[ui.py](../../srttools/ui.py) 静态注册 [SrtWorkbench](../../srttools/workbench.py) 与范围 FeaturePage。字幕整理采用横向文件列表/导出预览布局，格式始终可见，参数折叠，保存时选择目录；不存在组合任务、次要保存菜单或重复计划表。日志默认收起、进度只在忙碌时显示。

[preview.py](../../srttools/preview.py) 的 LivePreview 为两页共享的 180 ms 单次计时器与修订号调度：变化立即清空旧结果、禁用导出；取消过期读取，在全局 Worker 空闲后只计算最新参数。预览期间设置仍可编辑，扫描/导出时锁定；取消/关闭停止排队预览。MainWindow 显式 queued Slot 接收结果/错误，GUI 持有回调，finished 后 wait、清空回调并发 idle，始终单 Worker。TextPreview 每 50,000 字符分页可查看全文，提示与内容分离、不软换行；仅显示时规范 CRLF/CR，不修改输出字节。

[workflow.py](../../srttools/workflow.py) 为无 Qt 扫描与文档处理层：discover 发现 SRT/TXT，prepare_documents 按选定格式生成正文或原样 SRT/TXT；所有 GUI 格式均有实际可解码预览，解码失败不允许绕过。export_documents 只写同一 Prepared.data 到目标加扫描相对目录，不重新转换。相对路径在任何写入前完整校验，逐项复核来源与边界并复用 service 原子不覆盖发布，输入/输出各有 256 MiB 预算。

[subtitles.py](../../srttools/subtitles.py) 用整数毫秒完成 SRT 解析、结构 TXT 清理、文本排版与范围变换，不依赖 Qt。[service.py](../../srttools/service.py) 读取原始字节，生成不可变 Prepared 结果，保存来源 SHA-256；导出前复核来源，同目录暂存并以 Windows 不覆盖 rename 发布。CLI 共用服务层。

[build.py](../../tools/build.py) 使用干净子进程 PATH 调用 PyInstaller onedir，生成平铺 ZIP；[smoke.py](../../srttools/smoke.py) 用临时演示数据核对扫描、实时预览、三格式、预览/导出字节一致、混合 TXT、范围两格式、长文全文和多尺寸。自动验收默认离屏，避免桌面闪现。

处理数据只在内存与显式输出目录中；不上传字幕，不保存用户路径配置，日志仅当前会话。语义见 [ADR-001](../决策/ADR-001-字幕处理与安全导出.md)。
