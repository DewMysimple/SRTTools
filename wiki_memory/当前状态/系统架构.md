# 系统架构

[app.py](../../srttools/app.py) 创建 QApplication 与主窗口。[ui.py](../../srttools/ui.py) 静态注册 [SrtWorkbench](../../srttools/workbench.py) 与范围 FeaturePage。字幕整理为横向文件列表/正文阅读布局，文字参数折叠，导出时选择目录；不存在组合任务与计划表。导入后自动预览，参数变化撤销预览。一次只运行一个受控 QThread，扫描结果在旧 Worker 完全结束、idle 信号发出后才启动自动预览；取消扫描不续跑。任务期间锁定导航、参数、列表修改与保存操作。

[workflow.py](../../srttools/workflow.py) 为无 Qt 扫描与文档处理层：discover 发现 SRT/TXT，prepare_documents 按类型生成正文（次要操作可复制 SRT 或原样 TXT），export_documents 直接保存到目标加扫描相对目录。删除分类路由与多任务计划模型。相对路径在任何写入前完整校验，逐项复核来源、路径边界并复用 service 原子不覆盖发布。输入/输出各有 256 MiB 预算。

[subtitles.py](../../srttools/subtitles.py) 用整数毫秒完成 SRT 解析、结构 TXT 清理、文本排版与范围变换，不依赖 Qt。[service.py](../../srttools/service.py) 读取原始字节，生成不可变 Prepared 结果，保存来源 SHA-256；导出前复核来源，同目录暂存并以 Windows 不覆盖 rename 发布。CLI 共用服务层。

[build.py](../../tools/build.py) 使用干净子进程 PATH 调用 PyInstaller onedir，生成平铺 ZIP；[smoke.py](../../srttools/smoke.py) 在临时演示数据上核对扫描、自动预览、直接导出、次要保存、混合 TXT、范围两格式和多尺寸。自动验收默认离屏，避免测试启动与缩放造成桌面闪现。

处理数据只在内存与显式输出目录中；不上传字幕，不保存用户路径配置，日志仅当前会话。语义见 [ADR-001](../决策/ADR-001-字幕处理与安全导出.md)。
