# 系统架构

[app.py](../../srttools/app.py) 创建 QApplication 与主窗口。[ui.py](../../srttools/ui.py) 静态注册 [SrtWorkbench](../../srttools/workbench.py) 与范围 FeaturePage。字幕整理按来源、设置、预览、输出四区布局；网格参数始终展开，TXT/SRT 与时间戳独立，SRT 自动勾选。MainWindow 把工作台 footer 放在 QScrollArea 外，常驻输出路径默认 QStandardPaths 桌面/Test，可编辑或浏览。两页按钮明确“导出全部文件”，数量单独说明。日志默认收起、进度只在忙碌时显示。

[preview.py](../../srttools/preview.py) 的 LivePreview 为两页共享的 180 ms 单次计时器与修订号调度：变化立即清空旧结果、禁用导出；取消过期读取，在全局 Worker 空闲后只计算最新参数。预览期间设置仍可编辑，扫描/导出时锁定；取消/关闭停止排队预览。MainWindow 显式 queued Slot 接收结果/错误，GUI 持有回调，finished 后 wait、清空回调并发 idle，始终单 Worker。TextPreview 每 50,000 字符分页可查看全文，提示与内容分离、不软换行；仅显示时规范 CRLF/CR，不修改输出字节。

[workflow.py](../../srttools/workflow.py) 为无 Qt 扫描与文档处理层：discover 跳过当前输出子目录；prepare_documents 的 document 分支按 Options.output_format/include_timestamps 决定结构，统一应用文字设置。Prepared.has_style_markup 驱动当前文件标签提示。带时间戳必须严格解析、禁止整段合并、空条报错；CLI 与历史内核原字节接口保留。export_documents 只保存 Prepared.data，完整校验相对路径后逐项复核来源与链接边界，之后才创建缺失输出目录，再原子不覆盖发布。输入/输出各有 256 MiB 预算。

[subtitles.py](../../srttools/subtitles.py) 用整数毫秒完成 SRT 解析、结构 TXT 清理、文本排版与范围变换，不依赖 Qt。[service.py](../../srttools/service.py) 读取原始字节，生成不可变 Prepared 结果，保存来源 SHA-256；导出前复核来源，同目录暂存并以 Windows 不覆盖 rename 发布。CLI 共用服务层。

[build.py](../../tools/build.py) 使用干净子进程 PATH 调用 PyInstaller onedir，生成平铺 ZIP；[smoke.py](../../srttools/smoke.py) 用临时演示数据核对扫描、实时预览、TXT/SRT 与时间戳组合、预览/导出字节一致、混合 TXT、范围两格式、长文全文及多尺寸固定底栏。公开截图使用演示输出路径。自动验收默认离屏，避免桌面闪现。

处理数据只在内存与显式输出目录中；不上传字幕，不保存用户路径配置，日志仅当前会话。语义见 [ADR-001](../决策/ADR-001-字幕处理与安全导出.md)。
