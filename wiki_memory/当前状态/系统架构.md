# 系统架构

[app.py](../../srttools/app.py) 创建 QApplication 与主窗口。[ui.py](../../srttools/ui.py) 静态注册 [SrtWorkbench](../../srttools/workbench.py) 与范围 FeaturePage。综合工作台含来源表、四项可多选任务、可折叠文本参数、输出位置、任务计划表与预览。参数/任务/输出变化撤销计划；一次只运行一个受控 QThread，任务期间锁定操作。

[workflow.py](../../srttools/workflow.py) 为无 Qt 的扫描、组合计划与执行层：扫描相对目录映射，链接/联接排除，逐项异常，Text/SRT/Original/Clean 路由。原字节复制归档，不移动来源；执行复用 service 的摘要复核与原子不覆盖发布。预览不创建目录，输出输入各有 256 MiB 预算。

[subtitles.py](../../srttools/subtitles.py) 用整数毫秒完成 SRT 解析、结构 TXT 清理、文本排版与范围变换，不依赖 Qt。[service.py](../../srttools/service.py) 读取原始字节，生成不可变 Prepared 结果，保存来源 SHA-256；导出前复核来源，同目录暂存并以 Windows 不覆盖 rename 发布。CLI 共用服务层。

[build.py](../../tools/build.py) 使用干净子进程 PATH 调用 PyInstaller onedir，生成平铺 ZIP；[smoke.py](../../srttools/smoke.py) 在临时演示数据上核对扫描、组合任务、独立归档、TXT 清理、范围两格式和多尺寸。自动验收默认离屏，避免测试启动与缩放造成桌面闪现。

处理数据只在内存与显式输出目录中；不上传字幕，不保存用户路径配置，日志仅当前会话。语义见 [ADR-001](../决策/ADR-001-字幕处理与安全导出.md)。
