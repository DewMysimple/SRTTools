# 项目概览

## 项目目标与阶段

Subtitle Tools 0.7.0 是 Windows 本地字幕工具箱，含独立 SRT 时间轴、受限本地视频预览、本机草稿保护与恢复，以及实时设端、选中区间预览、字幕拆分、两点校准和安全另存为。[功能](../../docs/FEATURES.md)

## 核心入口

[App](../../src/app/App.tsx)、[字幕时间轴](../../src/features/timeline/TimelineWorkspace.tsx)、[流程](../../src/core/workflow.ts)、[Worker](../../src/workers/worker-logic.ts)、[原生入口](../../src-tauri/src/lib.rs)。运行与安装见[README](../../README.md)。
