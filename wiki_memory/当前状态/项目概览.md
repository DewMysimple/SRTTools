# 项目概览

SRTTools 1.4.0 是 Windows 中文本地字幕工具。「字幕整理」为文件列表与最终文件预览：显式选择纯文本 TXT、原字幕副本 SRT 或带时间轴 TXT，修改设置自动更新，同一导出入口保存不可变预览数据。格式、扩展名、编码和文件名可见，原样格式展示完整时间轴内容并停用不适用设置。取消旧任务菜单、分类目录与手动刷新要求，日志默认收起。长文每 50,000 字符分页但全文可访问；时间范围页也实时预览。保存直接进入所选目录，保留扫描相对层级，来源只读，同名编号。CLI 兼容保留。

工程采用 ObManage 的 Python/PySide6 分层和便携构建模式，没有引入与字幕无关的 SQLite 或仓库同步模块。远程使用用户指定的 SRTTools Git 仓库。
