# 项目概览

SRTTools 1.0.0 是 Windows 中文本地字幕工具，四个静态页面对应用户四项需求：SRT 原样转 TXT、SRT 提取正文、含 SRT 信息的 TXT 清理、时间范围导出 SRT/TXT。支持批次预览、编码选择、标签与排版、边界裁切、归零和毫秒偏移。来源只读，所有导出生成新文件。

工程采用 ObManage 的 Python/PySide6 分层和便携构建模式，没有引入与字幕无关的 SQLite 或仓库同步模块。远程使用用户指定的 SRTTools Git 仓库。
