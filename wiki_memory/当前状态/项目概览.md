# 项目概览

SRTTools 1.5.0 是 Windows 中文本地字幕工具。「字幕整理」按来源、设置、预览、输出四区布局，参数全部展开，格式 TXT/SRT 与保留时间戳分开控制；SRT 自动要求时间戳。所有工作台组合应用排版、格式清理与保存编码；无标签时明确说明开关没有文字变化。设置实时预览，保存不可变数据。底部固定输出路径默认桌面 Test，可编辑/浏览，只在导出时创建缺失目录。按钮为“导出全部文件”，数量、类型和失败项单独说明。保留全文分页、扫描层级、来源只读、同名编号与独立时间范围页；CLI 原字节模式兼容不变。

工程采用 ObManage 的 Python/PySide6 分层和便携构建模式，没有引入与字幕无关的 SQLite 或仓库同步模块。远程使用用户指定的 SRTTools Git 仓库。
