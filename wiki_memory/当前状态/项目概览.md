# 项目概览

SRTTools 1.2.0 是 Windows 中文本地字幕工具。「SRT 综合工作台」直接展示提取正文、归档 SRT、原样 TXT、清理 TXT 四项可组合任务，含文件夹递归扫描、输出计划与内容预览；不再以互斥模式选择功能。「时间范围导出」独立保留。支持编码、标签与排版、重置、裁切、归零和毫秒偏移。归档采用复制，来源只读，所有导出生成新文件。

工程采用 ObManage 的 Python/PySide6 分层和便携构建模式，没有引入与字幕无关的 SQLite 或仓库同步模块。远程使用用户指定的 SRTTools Git 仓库。
