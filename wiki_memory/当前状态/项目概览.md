# 项目概览

## 项目目标与阶段

- Subtitle Tools 是面向 Windows 10 / 11 x64 的本地字幕工具。主流程为导入 → 选择工具 → 设置参数 → 预览 → 确认导出。产品范围见[需求原稿](../../prompt/01_Subtitle_Tools_Codex_Prompt.md)。
- 当前开发版本为 0.3.0，已完成简繁正文写回、严格 GBK/GB18030、原生目录导入、独立可视对比和批量预设；最终干净源码发布正在验收。Explorer 为默认关闭的实验入口，本机实际菜单显示 BLOCKED，其余原生分项独立记录。[实际功能与限制](../../docs/FEATURES.md)、[本轮审阅](../../docs/REVIEW_v0.2.0_to_v0.3.0.md)
- v0.1.1 在 Windows 11 安装版验证了系统对话框、Explorer 拖放、授权、导出与卸载。环境级缺口与 v0.2.0 验收状态分别见[稳定性检查表](../../docs/RELEASE_CHECKLIST_v0.1.1.md)和[测试记录](../../docs/TESTING.md)。

## 核心入口

- 前端从 [main.tsx](../../src/main.tsx) 启动。路由在 [App.tsx](../../src/app/App.tsx)，工具及参数在 [tool-registry.ts](../../src/app/tool-registry.ts)。
- 桌面入口和打包配置分别在 [lib.rs](../../src-tauri/src/lib.rs) 与 [tauri.conf.json](../../src-tauri/tauri.conf.json)。依赖、启动和测试命令见[项目 README](../../README.md)。
