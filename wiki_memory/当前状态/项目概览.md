# 项目概览

SRTTools 1.3.0 是 Windows 中文本地字幕工具。「字幕整理」采用左侧文件列表、右侧正文阅读区，导入后自动预览，SRT 正文提取与 TXT 清理按文件类型自动处理。用户否定旧版多选组合与英文分类目录，现已移除任务卡片和输出计划表；主按钮直接导出正文，次要菜单独立复制原字幕或保存带时间轴的 TXT。保存直接进入所选目录，仅保留扫描相对层级。「时间范围导出」及 CLI 兼容保留。来源只读，所有导出新建、同名编号。

工程采用 ObManage 的 Python/PySide6 分层和便携构建模式，没有引入与字幕无关的 SQLite 或仓库同步模块。远程使用用户指定的 SRTTools Git 仓库。
