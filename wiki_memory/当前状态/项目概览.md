# 项目概览

## 项目目标与阶段

- Subtitle Tools 0.1.0 是面向 Windows 10 / 11 x64 的本地字幕工具。主流程为导入 → 选择工具 → 设置参数 → 预览 → 确认导出。产品范围见[需求原稿](../../prompt/Subtitle_Tools_Codex_Prompt.md)。
- 0.1.0 已提供文本清理、时间处理、转换、检测修复、多文件和双语合并、拆分、批量导出和处理历史。[实际功能与后续范围](../../docs/FEATURES.md)
- 首次 Windows x64 NSIS 构建、安装、启动和卸载已有历史验收记录。原生桌面交互待验收。[测试记录](../../docs/TESTING.md)

## 核心入口

- 前端从 [main.tsx](../../src/main.tsx) 启动。路由在 [App.tsx](../../src/app/App.tsx)，工具及参数在 [tool-registry.ts](../../src/app/tool-registry.ts)。
- 桌面入口和打包配置分别在 [lib.rs](../../src-tauri/src/lib.rs) 与 [tauri.conf.json](../../src-tauri/tauri.conf.json)。依赖、启动和测试命令见[项目 README](../../README.md)。

## 工作区背景

- 2026-11-04 在 Windows PowerShell 中从已有源码初始化 Git。初始化前无仓库或 revision，Agent 选择 `main` 作为首个分支。初始版本包含现有源码、示例、文档、测试和本次工程记忆。
- 用户指定 GitHub 仓库，使用 `origin`。接续时用 `git status --short --branch`、`git rev-parse HEAD` 和 `git ls-remote --symref origin HEAD` 重查实际状态。[项目 Git 规则](../../AGENTS.md)
