# 项目概览

## 项目目标与阶段

Subtitle Tools 是 Windows 本地字幕工具箱。0.5.0 新增独立 SRT 校时工作区，含时间轴、正文与精确时间编辑、撤销重做、校验和安全另存为。0.6.0 从已验 0.5.0 主线开展本地视频预览。[功能](../../docs/FEATURES.md)
