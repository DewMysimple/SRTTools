# 当前约束

用户明确要求四种灵活字幕处理、独立工程目录、指定 GitHub 远程、类似 ObManage 的架构、工程记忆和优秀 README/AGENT。源码与文档禁止写入私人字幕内容和绝对路径。

用户否定任务组合与英文分类目录，要求实时预览即导出。最新明确要求参数不折叠，TXT/SRT 与时间戳分开选择，四区边界明显，底部固定可自定义桌面 Test 输出路径；“导出（3）”不清楚，因此两页改为“导出全部文件”，数量、类型和失败项单独说明。SRT 必须有时间戳并解释，TXT 自由勾选；所有工作台组合应用文字设置，不再隐含原字节复制。无标记时提示清理开关不改变文字。来源不移动，扫描层级/无分类目录与 CLI raw 兼容继续有效。

两页参数变化立即撤销旧预览与导出资格，防抖后自动更新；取消过期任务，按修订号拒绝旧回调，导出只使用当前 Prepared.data。长文全文分页、不截断，提示不进入导出。工作台读取/结构失败项不可导出；普通 TXT 无时间轴不能生成带时间戳文件，不编造时间。输出路径编辑/浏览零写，点击导出、逐项来源复核后才创建缺失目录，失败直接可见。参数展开但日志仍可收起；自动测试离屏，不弹窗。

CLI 原样 TXT 输出保持字节；工作台按保存编码生成新内容、统一 LF，带时间戳从 1 编号并保留原时间/顺序/附加设置。不得静默跳过坏块、清理后空字幕或误删数字正文。时间以整数毫秒表示，范围左闭右开，裁切和归零后再加偏移。负时间、空结果、错误编码明确报错。

新文件导出永不覆盖既有文件。同名自动编号，预览后来源改变必须拒绝该项导出；批次部分失败可继续其他文件，必须逐项报告。取消保留已经成功的文件。

后续每轮实质修改完成测试、记忆更新、最终源码平铺 ZIP、提交推送与远端核验。二进制不提交 Git。详细约定见 [AGENTS.md](../../AGENTS.md)，交付步骤见 [开发验证与交付](../知识/流程/开发验证与交付.md)。
