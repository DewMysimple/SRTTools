# 当前约束

用户明确要求四种灵活字幕处理、独立工程目录、指定 GitHub 远程、类似 ObManage 的架构、工程记忆和优秀 README/AGENT。源码与文档禁止写入私人字幕内容和绝对路径。

用户否定多选任务组合与英文分类目录，最新又要求减少拥挤、实时预览并明确最终格式，预览即导出。采用单一「导出为」格式选择与一个保存入口，三格式均显示实际内容、扩展名、编码及文件名，取消原先绕过正文预览的次要保存菜单。原样格式停用不适用设置。保存无分类目录、保留扫描层级，复制而非移动，来源保护与 CLI 兼容继续有效。

两页参数变化立即撤销旧预览与导出资格，防抖后自动更新；取消过期任务，按修订号拒绝旧回调，导出只使用当前 Prepared.data。长文全文分页、不截断，提示不进入导出。无法解码的 GUI 原样保存必须先修正读取编码；CLI 原样模式仍允许原字节输出。输出目录在保存时选择、取消零写，错误直接可见。日志默认收起，自动测试仍离屏，不弹窗。

原样 TXT 输出保持字节；其他处理不得静默跳过坏块或误删数字正文。时间以整数毫秒表示，范围左闭右开，裁切和归零后再加偏移。字幕负时间、空结果、错误编码明确报错。原样转换解码失败仅限制预览。

新文件导出永不覆盖既有文件。同名自动编号，预览后来源改变必须拒绝该项导出；批次部分失败可继续其他文件，必须逐项报告。取消保留已经成功的文件。

后续每轮实质修改完成测试、记忆更新、最终源码平铺 ZIP、提交推送与远端核验。二进制不提交 Git。详细约定见 [AGENTS.md](../../AGENTS.md)，交付步骤见 [开发验证与交付](../知识/流程/开发验证与交付.md)。
