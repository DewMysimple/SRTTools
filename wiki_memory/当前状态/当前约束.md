# 当前约束

## 用户要求与技术约束

- 产品以 Windows 本地字幕处理为范围，默认简体中文。导入、预览和导出分离。字幕内容在本机处理，处理历史仅保留摘要元数据。产品边界以[需求](../../prompt/01_Subtitle_Tools_Codex_Prompt.md)和[功能清单](../../docs/FEATURES.md)为准。
- 原生读写要求当前会话明确授权。默认导出 `{name}_processed`，同名自动避让。单输入最多 32 MiB，单次导入与队列均最多 100 个文件、总计 128 MiB，单次原生输出最多 256 MiB。[文件边界](../../docs/ARCHITECTURE.md#ipc-与文件边界)
- 输入 SRT、VTT、CSV、ASS、SSA 和含时间行的 TXT。字幕或文本输出 SRT、VTT、CSV、ASS、TXT。支持 UTF-8 / BOM、UTF-16 LE / BE，GBK / GB18030 需手选导入。通用模型的格式损失及低置信度编码处理以[格式规范](../../docs/FEATURES.md#格式与编码)为准。

## 兼容性与操作边界

- 目标为 Windows 10 / 11 x64 和 WebView2。浏览器预览可验证 Web Worker 及下载流程，原生权限、目录与 Explorer 需桌面验证。
- 用户指定 standard 工程记忆和 [GitHub 远程](https://github.com/DewMysimple/SRTTools.git)。每次完整对话产生的项目更新都应在收尾提交并推送，包含有持久价值的记忆更新。只读或无更新的对话无需空提交。远程核对、暂存范围、冲突和失败处理遵循[根指令](../../AGENTS.md)。
- 用户授权[第六阶段任务书](../../prompt/06_SRTTools_v0.5.0-v0.6.0_时间轴与视频预览_Codex完整执行提示词.md)，将历史边界更新为独立 SRT 时间轴与本地只读视频同步预览。0.5.0 先验收与合并，0.6.0 在最新主线完成原生媒体安全 Gate 才进入正式播放与同步。媒体限定本次选择的单一文件，关闭后撤销，禁止全文件 IPC 与宽泛权限。项目许可证仍列公开发布前待决定，正式 tag、Release、附件上传及签名需另行决定。
- 最终本地交付固定在 `release-output/`，只保留最新一套可运行目录、ZIP 与 NSIS 安装器。先验证新产物，再可回滚替换；清理只允许已核实的项目产物，保护未知文件、用户数据、源码、依赖及默认编译缓存。[第四阶段任务书](../../prompt/04_SRTTools_v0.4.0_高级效率工具_Codex执行提示词.md)
- v0.2.0 差异预览属于展示层，导出使用既有 Worker 输出。预设只写用户显式保存的工具声明参数，输入文件、编码、输出目录、命名规则与临时授权保持独立。[功能范围](../../docs/FEATURES.md)
- v0.3.0 简繁保留原编号、时间、格式和换行，仅写正文；严格 GBK/GB18030 使用已验证 WHATWG 映射，拒绝不可表示或不能逐字往返的字符。跨文档对比不信任 cue ID，解析/编码未确认时不给假增删。[实现与边界](../../docs/FEATURES.md)
- 目录导入只从本次原生选择获得范围，拒绝 reparse，最多 5 层 / 2,000 目录项并遵守队列预算。Explorer 仅本用户六扩展专属键，默认关闭，不改系统策略或默认关联；本机菜单显示不能实证时按任务书保留实验性，不能写已生效。[第四阶段任务书](../../prompt/04_SRTTools_v0.4.0_高级效率工具_Codex执行提示词.md)
