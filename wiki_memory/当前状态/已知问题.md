# 已知问题

自动编码仅认 UTF-8 与含 BOM 的 UTF-16；旧编码必须手动选择。标准 SRT 必须有合法时间轴、非空正文和块间空行；无块间空行不会猜测修复。TXT 中无法识别的箭头行报错，避免静默删除。

单文件上限 64 MiB、批次输入及组合输出预览分别上限 256 MiB，预览区限 50,000 字符但导出完整。处理期取消在文件边界/发布前检查，解析大文件时不会立即终止。已有导出不会因后续失败而回滚。

递归扫描跳过名为 Text/SRT/Original/Clean 的子目录，避免重新处理输出；同名的真实输入目录需显式选为扫描根或添加具体文件。多个扫描根映射到同一输出根时，同名通过编号保留，不自动推测课程归属。CLI 保持单任务，不提供 GUI 组合归档参数。

当前不持久化界面配置或历史路径。文件保护针对正常并发、名称冲突和陈旧预览，不宣称防御同权限恶意进程替换整个目录树。Windows 为正式支持平台，未验收其他平台桌面与发布包。

行为定义见 [使用指南](../../docs/使用指南.md)。
