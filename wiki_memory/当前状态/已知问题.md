# 已知问题

## 未解决问题与影响

- Windows 11、100% DPI 和已装 WebView2 的环境已有安装版证据。Windows 10、无 WebView2 的干净系统、125% / 150% / 200% DPI 未验。传统 MAX_PATH 以上的系统选择器与完整原生批量预算流程仍未验。
- 当前 NSIS 安装包未配置签名。格式与功能限制另见[功能文档](../../docs/FEATURES.md)。
- 本机 Win11 的 HKCU 菜单登记和 Shell 查询成功，真实传统菜单未显示应用项，因此菜单显示/点击导入 BLOCKED。Agent 按任务书 §9 采用实验性、默认关闭和登记状态不声称可见的降级；CLI 转发、物理拖放、启停/更新/路径修复/卸载保护及恢复有独立原生 PASS。未把 UAC 推测写成已证实根因。[本轮审阅](../../docs/REVIEW_v0.2.0_to_v0.3.0.md)

## 复现与临时处理

- 原生拖放可报告独占锁导致的读取失败并隔离其他文件。系统选择器打开同一锁定文件的 UI 自动化未完成，复现路径见[原生验收矩阵](../../docs/RELEASE_CHECKLIST_v0.1.1.md)。
- 在相应 Windows 版本、DPI 和无 WebView2 的环境按矩阵补测。原生权限、超长路径和批量预算分别查看自动化与桌面覆盖范围。
- 需要正常可验证用户环境补验 Explorer 菜单显示。本轮未为通过该项而改机器级设置或默认文件关联；可继续使用文件选择、目录导入和拖放。
