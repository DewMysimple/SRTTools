# 工程记忆导航

初始布局为 `standard`，由用户于 2026-11-04 指定。当前布局以 `.memory.json` 为准。

新会话先读[根指令](../AGENTS.md)和本页的[记忆维护协议](AGENTS.md)，再依次读[项目概览](当前状态/项目概览.md)、[当前约束](当前状态/当前约束.md)和[当前待办](当前状态/当前待办.md)。按任务补读架构、已知问题及关联来源。追溯历史时从工作日志 MOC 按类型或关键词定位。

日常开发直接遵循项目内协议，不调用 wiki-memory Skill；仅用户明确要求记忆管理时使用 Skill。
