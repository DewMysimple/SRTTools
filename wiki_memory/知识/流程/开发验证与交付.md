# 开发验证与交付

创建 Python 3.14 虚拟环境，按 requirements-dev.txt 安装。测试使用临时目录，全部回归与记忆 index/check；GUI --smoke-test 走真实 Worker、实时预览、TXT/SRT/时间戳组合、长文全文、混合 TXT 与范围两格式。测试先将可见输出栏改到临时路径，不向真实桌面 Test 写入；默认目录测试替换系统桌面解析。检查格式标记有/无/清除、参数常展开、固定底栏、明确批次范围、路径无效/浏览取消/只在导出创建目录、来源与链接保护；保留防抖、旧结果拒绝、GC/主线程、取消关闭与字节一致性测试。多尺寸含最小 850×620、日志展开、长文件名；公开截图输出路径使用演示盘符而非用户账户。

QThread 的结果与错误连接主窗口显式 queued Slot，由 GUI 持有 Python 回调，finished 后 wait 并清空回调。自动预览改造期间曾在全量测试 GC 时进程中止；该分派方式通过连续全量测试及运行中 GC 压力验证。不要恢复按任务临时 lambda 直接连接 Worker 结果信号的路径；新增异步行为验证 GUI 线程归属与重复任务生命周期。Qt 线程语义参考 [官方文档](https://doc.qt.io/qt-6/threads-qobject.html)。

用户反馈自动验收启动和缩放可见窗口导致桌面闪烁。--smoke-test 默认设置 QT_QPA_PLATFORM=offscreen，正常启动不受影响。仅专用测试桌面需要原生可见验收时显式设置 windows；本机不反复弹测试窗口。

英文 Windows 的重定向输出可能使用 cp1252，无法打印中文；GitHub CI 显式设置 PYTHONUTF8=1 与 PYTHONIOENCODING=utf-8。出现 UnicodeEncodeError 时先检查输出编码，不能误判为记忆内容损坏。

冻结 GUI 失败时 CI 输出 workspace.error.txt 的堆栈。受限桌面可能把请求窗口尺寸裁小，滚动条断言必须按实际窗口高度判断；所有尺寸都仍需验证无横向溢出、导出按钮可滚动到达。

构建前确认 dist/SRTTools 在本工程且旧 SRTTools.exe 退出；运行 tools/build.py。检查平铺 ZIP 根层 EXE、_internal、使用说明和许可证、CRC，运行冻结 EXE 的演示验收并检查退出码与截图。

必要时更新 docs/images 的演示截图，只选择已清除临时私人路径的最终截图。更新日志与当前状态，显式 git add 本轮文件，提交推送并比对本地 HEAD 与远端 main 哈希。远端不可用如实报告，禁止先写成功。
