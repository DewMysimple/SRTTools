# 字幕处理内核

[subtitles.py](../../../srttools/subtitles.py) 定义 Cue(start,end,text,settings)、时间输入/格式化、parse_srt、clean_txt、select_range 和 render_srt。所有时间为整数毫秒，多行与附加设置保留。workflow.prepare_document 为工作台将 TXT/SRT、是否保留时间戳与文字设置组合，标签清理两格式均可用；has_style_markup 指示当前输入正文有无可清理标记。带时间戳必须有合法结构，禁止整段合并，清理后空条报错；LF 与保存编码生成新内容。CLI/范围服务原接口不变。

[service.py](../../../srttools/service.py) 的 Options 为冻结 dataclass；prepare 只读，Prepared 保存完整输出 bytes 和 SHA-256。prepare_batch / export_batch 对每项成功与 Failure 逐一回报。Windows 使用不覆盖 os.rename 原子发布，NTFS/FAT/exFAT 不需要硬链接；非 Windows 服务路径使用硬链接发布，但该平台未作为正式交付验收。

[CLI](../../../srttools/cli.py) 不带输出目录时只预览，指定 -o 才导出，任何文件失败退出 1。核心边界见 [ADR-001](../../决策/ADR-001-字幕处理与安全导出.md)。
