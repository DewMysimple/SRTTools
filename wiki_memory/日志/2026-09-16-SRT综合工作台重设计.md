# SRT 综合工作台重设计

## 要求与参考

用户否定把功能隐藏在模式下拉框中，要求参考批量字幕脚本重新设计工作台。参考包含递归扫描、纯文本提取、独立整理到 SRT/、组合提取整理到 Text/SRT/。用户进一步明确归档采用复制、保留来源，不移动原文件。

## 实现

- 版本 1.2.0，改名 SRT 综合工作台，四项可组合任务直接展示，来源/任务/输出计划/内容预览同页。
- 新增无 Qt workflow 扫描/计划/执行层，扫描相对层级、输出目录排除、链接和联接保护、异常可见；预览零写。
- Text/、SRT/ 或 Text/SRT/、Original/、Clean/ 路由；归档与原样保留字节，来源摘要复核、原子发布及同名不覆盖。
- 保留独立时间范围页与 CLI 语义；可折叠文本参数、重置、多尺寸适配、全局受控任务互斥。
- 用户指出测试窗口闪现，确认为自动启动、缩放和最大化验收导致；--smoke-test 改为默认离屏，不影响正常运行。
- README、使用指南、演示截图和当前有效工程记忆同步。
