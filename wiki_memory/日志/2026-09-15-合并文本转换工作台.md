# 合并文本转换工作台

用户要求将原样转 TXT、SRT 提取正文、TXT 字幕清理合并为一个工作台，通过工具栏选择处理方式并优化设置。

实现两个静态工作台，前三种共用文件列表、输入/输出设置、预览和输出位置。模式切换保留文件及正文偏好，但撤销旧预览与导出资格。原样模式将输入编码标为「预览编码」，禁用输出编码、排版、去标签。重置选项保留处理方式、输入和输出位置；范围页把毫秒偏移独立成带标签的一行，改善小窗口宽度。业务内核和 CLI 语义不变，版本更新为 1.1.0，README 与使用指南同步。

验证：52 项应用测试通过；源码 GUI 演示执行三种文本模式、范围 SRT/TXT 导出，退出 0。覆盖原样字节、模式切换预览失效、TXT 不兼容报错、设置保留与重置、任务工具栏禁用，以及小/普通/大窗口和最大化。最初扩展尺寸测试发现极小屏幕范围页横向溢出，偏移分行后回归通过。

旧程序退出后已构建 1.1.0，冻结 GUI 与 ZIP 解压启动验收均退出 0。ZIP 根层包含 EXE、_internal、说明和许可证，CRC 通过，无包装目录。初次源码提交 dbfb85d 已推送并核对远端一致。

远程 CI 的回归、记忆检查和构建通过，但新增界面验收用请求高度判断滚动条，在受限桌面失败。补充 CI 错误堆栈输出后定位到该断言；改为按实际窗口高度判定，仍检查所有尺寸的横向溢出和导出按钮可滚动到达。修正提交 04b7479 的完整 Windows CI（运行 34931921927）已通过，包括冻结 GUI 和 ZIP 产物上传。
