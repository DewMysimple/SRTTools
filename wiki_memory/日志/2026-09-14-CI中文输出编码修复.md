# CI 中文输出编码修复

- 目标：完成首版 GitHub Windows 自动验收，修复英文系统的中文输出失败。

首版提交 `3bac050` 已推送并核对远端一致。GitHub 首轮应用测试与记忆工具测试通过，但记忆检查在输出成功提示时抛出 UnicodeEncodeError。读取该次任务日志确认是英文 Windows 的默认 charmap 编码；本地强制 cp1252 已复现同一错误，页面本身没有校验失败。

工作流固定 PYTHONUTF8=1 和 PYTHONIOENCODING=utf-8，确保中文输出在重定向日志中保留。应用运行代码和现有便携包没有变化。CI 重跑结果以 GitHub 任务状态为准，不提前声明成功。

另已将首版 ZIP 解压到隔离验收目录，确认根层 EXE 与原构建 EXE SHA-256 相同；解压后的程序执行四页完整演示验收退出 0，证明便携 ZIP 可直接运行。
