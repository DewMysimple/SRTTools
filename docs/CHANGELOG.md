# 更新记录

## 0.3.0 · 主线、严格转换与发布管理

- 将 v0.2.0 已验收开发分支快进合并并推送主线，保留历史。
- 固定 `release-output/` 最新可运行目录、ZIP 与 NSIS；真实解压冒烟及哈希验证后可回滚替换，默认干运行清理，保护未知文件、外部 target、活动进程与唯一旧副本。
- 简繁工具采用离线 OpenCC 词组词典，正文跨度写回保留六种格式的编号、时间、换行与控制布局，接入预设和差异预览。
- GBK / GB18030 独立严格编码，字符定位、全输出往返及 Unicode 全标量回归，拒绝有损兼容别名。许可证随安装器与 ZIP 分发。
- 原生文件夹导入支持过滤、可选递归、Channel 进度和取消保留；同句柄读取、reparse 防护、深度/目录项/容量限制。修复 Unicode 名称扩张导致的误去重。
- 独立对比共享可视化差异，保留原列表诊断与无正文 JSON，解析或编码未确认时不制造假删除；批量页复用相同工具预设并验证导出字节一致。
- 默认关闭的 HKCU Explorer 菜单，单实例安全转发，显式启停/修复路径及受保护的安装更新/卸载。实际验收和环境缺口见[测试记录](TESTING.md)。

## 0.2.0 · 差异预览与参数预设

- 差异预览按 cue ID、内容锚点和局部顺序配对，突出显示正文、毫秒时间与编号变化。支持仅变化筛选、20 行分页、多输出切换和有提示的回退。
- 按工具保存和应用命名预设，支持显式更新、重命名、确认删除和表单重置。应用预设清除旧预览与导出状态。
- 预设只保存注册的工具参数。分离损坏数据与未知版本，固定键本地存储支持浏览器和桌面。原生 Store 支持原子替换，并在 Windows 同目录重命名受限时保留已提交值以便恢复。
- 增加差异核心、各格式输出一致性、预设持久化、Chromium 流程及原生 Store 写入失败回归。实际验证见[测试记录](TESTING.md)。

## 0.1.1 · 稳定性

- 取消选择或重复添加原生文件时保留既有队列与处理结果。更改输入、工具、参数或编码时清除旧预览与可导出结果。
- 批量导出首次重新授权目录后，后续文件沿用实际保存位置。命名模板保留原文件名中看似替换符号的字面内容。
- 空文件和无可处理条目的输入停止字幕导出，检测和文件信息仍可查看。损坏的历史或设置只影响对应数据。
- 增加 Windows 长 Unicode 路径与大小写重名的原生回归，验证新副本发布后原文件字节仍完整。
- 修复导出名的 Windows 保留设备名检测，覆盖带上标数字的 COM / LPT 名称。[Microsoft 文件命名规范](https://learn.microsoft.com/windows/desktop/FileIO/naming-a-file)
- 增加 GitHub Actions 基础检查，覆盖前端、Chromium 与 Windows Rust。
- 实际检查、原生交互和发布条件见 [v0.1.1 发布检查表](RELEASE_CHECKLIST_v0.1.1.md)。
