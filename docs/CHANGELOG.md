# 更新记录

## 0.5.0 · 字幕时间轴

- 新增独立 SRT 校时工作区，可拖动平移、修剪两端、缩放滚动、吸附、多选微调和插入删除。
- 列表、轨道与检查器联动，支持多行正文、精确时间、撤销重做、恢复原稿、共享诊断和差异预览。
- 安全另存为保留原字幕文件，文件切换和窗口关闭检查未保存草稿。导出使用既有严格编码与 SRT 往返校验。
- 便携版和 NSIS 安装版均须通过原生时间轴与原工作流验收才允许晋升。证据见 [v0.5.0 QA](TIMELINE_V0.5_QA.md)。

## 0.4.0 · 高级效率工具（2026-11-04；2026-11-05收尾复核）

- 批量页加入线性处理流程，八种现有单文档操作可启停、重排和配置；复用统一Parser、Worker队列与差异预览，一次解码/解析、末端严格导出。ASS/SSA/VTT混合操作需明确同意规范化；纯简繁保持原文标记边界。
- 我的流程本地保存/更新/重命名/复制/删除；工具与流程统一JSON选择导出、隐私确认、导入影响预览和三种冲突策略。固定独立存储键、旧工具预设兼容、损坏/未来数据隔离、两键原子事务与中断恢复。
- 文件夹批量与流程共享安全层级/平铺输出树、ZIP和原生目录计划；多根别名、重名避让、源/目标重叠拒绝、reparse防护、逐项失败/取消/重试保留已成功项。
- 可重复100/1k/10k/50k、10/50/100文件与真实Worker基准；修复自动换行长行反复移动数组的瓶颈，保持输出哈希和旧断行语义。
- 增加Worker超时/清理、实际ASS词组边界、预设中断/隔离、原生目录安全、UI流程/预设交换/处理重试状态回归。正式ZIP/NSIS、主线与清理结果以[本轮发布审阅](REVIEW_v0.4.0_RELEASE.md)为准，正式311 Vitest/42 Rust/72 Chromium、22项PS5安全/状态、ZIP原生流程及固定Setup安装/卸载均通过。

- 收尾复核补齐CI/发布共享版本门槛、实际PS5解析/BOM检查、当前截图及锁定依赖许可；修正原生QA的夹具和异步页面/控件等待，未修改字幕业务。新候选重新通过全量质量、ZIP和固定Setup安装/卸载；公开发布与项目LICENSE仍待维护者决定。[收尾报告](RELEASE_CLOSURE_v0.4.0.md)

## 0.3.0 · 主线、严格转换与发布管理

- 将 v0.2.0 已验收开发分支快进合并并推送主线，保留历史。
- 固定 `release-output/` 最新可运行目录、ZIP 与 NSIS；真实解压冒烟及哈希验证后可回滚替换，默认干运行清理，保护未知文件、外部 target、活动进程与唯一旧副本。
- 简繁工具采用离线 OpenCC 词组词典，正文跨度写回保留六种格式的编号、时间、换行与控制布局，接入预设和差异预览。
- GBK / GB18030 独立严格编码，字符定位、全输出往返及 Unicode 全标量回归，拒绝有损兼容别名。许可证随安装器与 ZIP 分发。
- 原生文件夹导入支持过滤、可选递归、Channel 进度和取消保留；同句柄读取、reparse 防护、深度/目录项/容量限制。修复 Unicode 名称扩张导致的误去重。
- 独立对比共享可视化差异，保留原列表诊断与无正文 JSON，解析或编码未确认时不制造假删除；批量页复用相同工具预设并验证导出字节一致。
- 默认关闭的实验性 HKCU Explorer 菜单，单实例安全转发，显式启停/修复路径及受保护的安装更新/卸载；本机实际菜单显示 BLOCKED。实际验收和环境缺口见[测试记录](TESTING.md)。
- 修正 Explorer 浏览器验收的事件监听模拟，确定性覆盖 React StrictMode 迟到订阅；同源两次正式发布与一次发布前故障保留均实际验证。

## 0.2.0 · 差异预览与参数预设

- 差异预览按 cue ID、内容锚点和局部顺序配对，突出显示正文、毫秒时间与编号变化。支持仅变化筛选、20 行分页、多输出切换和有提示的回退。
- 按工具保存和应用命名预设，支持显式更新、重命名、确认删除和表单重置。应用预设清除旧预览与导出状态。
- 预设只保存注册的工具参数。分离损坏数据与未知版本，固定键本地存储支持浏览器和桌面。原生 Store 支持原子替换，并在 Windows 同目录重命名受限时保留已提交值以便恢复。
- 增加差异核心、各格式输出一致性、预设持久化、Chromium 流程及原生 Store 写入失败回归。实际验证见[测试记录](TESTING.md)。

## 0.1.1 · 稳定性

- 取消选择或重复添加原生文件时保留既有队列与处理结果。更改输入、工具、参数或编码时清除旧预览与可导出结果。
- 批量导出首次重新授权目录后，后续文件沿用实际保存位置。命名模板保留原文件名中看似替换符号的字面内容。
- 空文件和无可处理条目的输入停止字幕导出，检测和文件信息仍可查看。损坏的历史或设置只影响对应数据。
- 增加 Windows 长 Unicode 路径与大小写重名的原生回归，验证新副本发布后原文件字节仍完整。
- 修复导出名的 Windows 保留设备名检测，覆盖带上标数字的 COM / LPT 名称。[Microsoft 文件命名规范](https://learn.microsoft.com/windows/desktop/FileIO/naming-a-file)
- 增加 GitHub Actions 基础检查，覆盖前端、Chromium 与 Windows Rust。
- 实际检查、原生交互和发布条件见 [v0.1.1 发布检查表](RELEASE_CHECKLIST_v0.1.1.md)。
