# Subtitle Tools v0.4.0 发布说明草稿

这是发布文案草稿，尚未创建公开tag、GitHub Release或上传附件。项目许可证暂未决定；正式公开发布需维护者另行确认。

Subtitle Tools是Windows本地字幕工具箱，字幕默认在电脑上处理，不上传文件。本版提供：

- 组合处理流程：将删除空白、清空格、替换、简繁、换行、去HTML、时间偏移和重新编号组成最多20步的方案；保存后可反复使用，执行前查看真实差异。
- 工具与流程预设JSON交换：选择要分享的预设，预览导入冲突，再跳过、改名或确认覆盖；已有工具预设继续可用。个人输入的查找/替换文字会随预设分享。
- 文件夹批量：选择保留目录层级或全部平铺，多根目录和重名有可见规划；支持ZIP及独立目录输出，默认不覆盖源字幕。
- 可视化对比与安全导出：逐项诊断、严格编码、失败隔离、取消和重试；简繁独立处理保留样式/换行，混合流程遇布局损失需明确同意。
- 性能改进：一次流程减少重复解析和编解码，优化超长单行换行。可复验数据与测量范围见[性能报告](PERFORMANCE_v0.4.0.md)。

本工具不包含视频播放器、视频时间轴或轨道编辑。

## 安装与下载

当前候选文件在工程的`release-output/`：`SRTTools-Setup.exe`供当前用户安装；`SRTTools.zip`解压后运行`SRTTools/subtitle-tools.exe`。两者需要Windows x64和Microsoft Edge WebView2 Runtime。校验文件为`SHA256SUMS.txt`；逐件哈希和新构建验证见[收尾报告](RELEASE_CLOSURE_v0.4.0.md)。

GitHub Releases尚无公开下载版本。公开分发后应把经批准的实际Release链接和附件校验值补入文案；当前不提供尚不存在的下载链接。

## 已知限制

实际桌面验收以Windows11、100% DPI、已装WebView2环境为限。Windows10、125%/150%/200% DPI、无WebView2干净系统及超MAX_PATH系统选择器尚未验收。安装包未签名。Explorer菜单为默认关闭的实验入口，真实显示/点击仍BLOCKED，登记成功不代表菜单可用。

单文件32MiB、队列100文件/128MiB、原生输出会话256MiB。普通格式转换可能丢失ASS/SSA样式及VTT设置；严格GBK/GB18030拒绝不可往返字符，可改用UTF-8。没有自动更新功能。
