## 已修复与复现

- 处理后取消文件选择或重复添加同一原生文件，队列未变化时保留现有结果。实际更换文件、工具、参数或编码后必须重新处理。
- 在已保存目录 A 的偏好下重启，第一次批量导出时改选 B，后续文件沿用 B。浏览器模拟原生 IPC 的回归断言不重复询问，且无须改写设置。
- 其他回归包括空输入、损坏的单项持久化数据、文件名模板字面量、长 Unicode 路径和 Windows 保留设备名。详见[更新记录](CHANGELOG.md)与本阶段提交。测试数据为公开合成字幕或运行时生成数据。
