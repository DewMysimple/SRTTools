# SRTTools 使用指南

SRTTools 1.3.0 是本地字幕工具。解压便携包，直接运行根目录的 `SRTTools.exe`；请保留旁边的 `_internal` 文件夹。

## 字幕整理

页面只有一份文件列表和一块正文阅读区，不需要选择任务组合。

1. 添加 SRT、TXT 或文件夹，也可以直接拖入。添加文件夹时可选是否包含子文件夹。
2. 自动读取完成后，左边选择文件，右边阅读正文。SRT 会去掉时间轴与序号；TXT 会自动清理残留的字幕结构。
3. 点击「导出正文」，在弹出的目录选择器中选择保存位置。按钮上的数量代表整批可导出的文件，不只是当前查看的文件。

例如 `课程.srt` 直接保存为所选目录里的 `课程.txt`，不会额外创建分类文件夹。目录扫描保留相对层级，例如导入目录里的 `第一章/课程.srt` 保存成 `第一章/课程.txt`。手动添加的文件直接保存到所选目录；多个来源同名时自动编号为 `课程 (2).txt`。

左边的「移除」「清空」只调整本次列表，不删除文件。导入新文件或移除文件后自动重新预览。点击文件状态可以通过悬停查看完整错误或实际保存路径，文件名悬停显示完整来源路径。读取失败的文件仍留在列表，可点击查看原因；有效文件仍可导出，失败数不会被隐藏。

选择保存位置前没有任何磁盘写入；取消目录选择不会导出。原文件始终保留，已有文件永不覆盖。导出后按钮会停用，若需再次保存，先「更新预览」。

## 文字设置

点击「文字设置」展开编码和排版参数。修改后旧预览失效，请「更新预览」再导出。

- 读取编码：自动识别 UTF-8（含可选 BOM）或含 BOM 的 UTF-16。旧编码需手动选择 GB18030、Big5 或 Windows-1252。
- 排版：保留分行与段落、每条字幕一行、合并为一段。
- 保存编码：UTF-8、带 BOM 的 UTF-8 或 UTF-16。默认 UTF-8。
- 去除字幕样式标签：清理常见 b/i/u/s/font/ruby/rt/span 等标签，把 br 变为换行，解码 HTML 实体；未知标签不擅自删除。

「恢复默认」恢复自动读取编码、UTF-8 保存、保留分行、关闭去标签；保留文件、扫描提示与最近保存目录。

SRT 严格解析，不猜测修复损坏的字幕块。TXT 仅移除合法时间轴和紧邻时间轴的块首数字序号，保留年份、正文数字与普通段落。无法识别的箭头行会报错，避免悄悄丢失内容。整理后的文字使用 LF 换行，末尾保留一个换行。

## 其他保存方式

这两个入口在底部的「其他保存方式」菜单中，每次独立执行，不与正文导出组合。

- **复制原字幕到…**：把列表中的 SRT 按原字节复制到所选位置，使用原文件名。来源不移动、不删除。
- **另存为带时间轴的 TXT…**：把 SRT 原样保存为同名 TXT，序号、时间轴、正文、编码、BOM 和换行完全不变。

两种操作均保持扫描相对层级、同名自动编号，不受正文排版和输出编码设置影响。即使 SRT 正文解析失败，也可以单独复制。列表中的 TXT 不适用于这两个入口，会显示未保存的原因；不会被静默当作成功。

## 文件夹扫描与安全

扫描只读取普通 SRT/TXT，不跟随链接或目录联接。会跳过本次会话已选保存目录（如果它作为扫描子目录出现），但不会根据目录名称忽略字幕。首次扫描时尚不知道将来的保存位置，建议来源与输出分开存放。明确把保存目录选为扫描根仍可读取其中的文件。

读取失败和取消保留已发现的文件，并明确提示列表可能不完整。取消扫描后不会自动启动新的预览任务，可以自行「更新预览」。

保存前按摘要复核来源内容，变化时拒绝导出并要求重新预览。输出先写同目录临时文件，再原子发布，不覆盖任何原文件或既有输出。同名自动编号；可把来源目录选作保存位置，同样不会覆盖输入。

全局一次只运行一个后台任务。取消在文件边界或发布前生效，已保存的文件不回滚；未保存项逐文件报告。任务中关闭窗口会请求取消，结束后再次关闭即可。

## 时间范围导出

在左侧进入独立页面，添加 SRT、设置范围、生成预览、选择已存在的输出目录，再「导出全部有效项」。生成 `_range.srt` 或 `_range.txt`。

开始和结束支持秒数、分:秒、时:分:秒。例如 `120` 或 `02:00` 均代表 2 分钟；`2` 代表 2 秒。毫秒可用逗号或点号。结束必须晚于开始。

- 默认选择与范围有交集的字幕，也可选择整条完全包含、开始时间位于范围。
- 范围左闭右开，在结束点才开始的字幕不纳入。
- 「裁切跨边界字幕」仅裁切时间，不截断正文。
- 「以范围起点为零」适合对应的截取视频。
- 毫秒偏移最后应用；会产生负时间的组合报错，不静默丢字幕。

新 SRT 从 1 编号，保留正文、样式与时间轴附加设置。乱序和重叠会提示，不自动重排。正文排版和去标签仅对 TXT 生效。范围内没有字幕时不生成空输出。

## 限制与隐私

单文件上限 64 MiB，整批输入和输出预览分别上限 256 MiB。界面显示前 50,000 字符，保存保留全文。解析大文件时，取消可能需要等待当前文件处理完成。

本地处理，不上传、不翻译、不做语音识别或语义改写。日志仅保留本次会话最新 300 行，最新在最上面。不持久保存个人文件列表、路径或设置。

## 命令行与开发

命令行保持兼容：`python -m srttools.cli --help`。单任务 `raw`、`text`、`clean`、`range` 与原有后缀不变；不指定 `-o` 只预览，指定已存在的输出目录才导出。任何文件失败返回 1，全部成功返回 0。

自动界面验收使用 `--smoke-test 截图路径`，只操作临时演示数据，默认离屏运行，不闪现测试窗口。开发、构建及平铺 ZIP 交付说明见源码 README。
