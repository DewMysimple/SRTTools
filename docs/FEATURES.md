# 功能与限制

当前版本为 0.2.0。工具列表只提供已经实现的功能。

## 工作空间

- 五个主导航：首页、全部工具、批量处理、处理记录、设置。
- 工具按文本、合并拆分、格式、检测修复、时间、文件分类，支持名称和关键词搜索。
- 文件队列跨页面共用，允许排序、移除和清空；切换工具会清除该工具的临时预览结果。
- 文件导入、参数配置、只读预览与实际导出分开。处理失败保留输入和参数，写入失败保留结果。
- 设置和最近 200 次任务摘要保存在本机。预览和字幕全文不会写入历史。

## 可用工具

| 类别 | 功能 | 行为 |
| --- | --- | --- |
| 文本 | 查找替换 | 普通文字默认不区分大小写；可启用区分大小写和 Unicode 正则，校验非法表达式 |
| 文本 | 删除空白 | 删除只包含空白 / 不可见字符的条目 |
| 文本 | 空格清理 | 行首行尾去空格、合并连续水平空白，保留多行结构 |
| 文本 | 文本提取 | 输出 TXT，可保留或合并字幕内换行 |
| 文本 | 删除重复 | 仅连续重复或所有相同正文，保留首次出现的条目 |
| 文本 | 标点 / 大小写 | 常见中英文标点映射；英文大写、小写、单词首字母大写 |
| 文本 | 自动换行 / HTML 清理 | Unicode 字符计数、优先空格断行；移除标签、还原常见实体 |
| 合并 | 多文件合并 | 按文件顺序或开始时间排序，保留时间，重新编号 |
| 合并 | 双语合并 | 恰好两份文件，编号或开始时间容差匹配，上下顺序可交换；未匹配条目均保留并统计 |
| 拆分 | 按条数 / 时间 | 条数分组；时间点拆成两份，跨界字幕在两侧裁剪，默认保留绝对时间 |
| 对比 | 字幕对比 | 比较两文件相应条目的文字与时间，生成 JSON 报告；并非自动语义对齐 |
| 格式 | 格式转换 | 导入 SRT / VTT / CSV / ASS / SSA / 带时间 TXT；输出 SRT / VTT / CSV / ASS / TXT |
| 检测 | 字幕检测 | 结构、编号、非法 / 倒序 / 重叠时间、空白、重复、疑似乱码、每行超过 42 字符、时长小于 500 ms 或大于 10 s |
| 修复 | 重新编号 | 从 1 连续编号；所有标准字幕序列化也会连续编号 |
| 修复 | 检测与修复 | 重新编号、删除空白；无效时间保留 / 删除 / 延长至开始后 1 s；重叠保留 / 缩短前项，完成后重新检测 |
| 时间 | 偏移 | 整数毫秒，正延后、负提前；默认停止无效结果，可明确选择裁到零或删除无效条目 |
| 时间 | 显示时长 | 增减结束时间、设置最短 / 最长时长；默认拒绝无效时间，可能新增的重叠会提示 |
| 时间 | 范围裁剪 | 保留与范围相交条目，裁剪边界；完全无条目时拒绝空范围 |
| 文件 | 编码与换行 | 字幕规范化后导出为 UTF-8 / BOM、UTF-16 LE / BE，CRLF / LF |
| 文件 | 批量重命名导出 | 模板 `{name}` 与 `{index}`，生成新副本，不改原文件路径或名称 |
| 文件 | 信息与统计 | JSON 报告含格式、编码、条目、Unicode 字符数、跨度、诊断，不含字幕全文 |

大部分文本工具只改正文；删除工具会减少条目，导出默认重新编号。所有时间均使用整数毫秒。转换、编码和重命名导出会经统一模型重新序列化，不能保留原文件的字节布局。

## 格式与编码

| 格式 | 输入要求与转换注意事项 |
| --- | --- |
| SRT | 容忍 BOM、CRLF / LF / CR、点号毫秒、缺失编号和额外空行；错误结构返回诊断，不能静默跳过后直接生成字幕 |
| VTT | 识别 WEBVTT 头、可选 cue 标识与设置；头部映射、位置、样式和区域信息不保留，会提示 |
| CSV | 恰好 `index,start,end,text` 四列（顺序可调整），时间为 `HH:MM:SS,mmm`；逗号、引号、多行按 CSV 转义；额外列会拒绝，避免丢数据 |
| ASS / SSA | 使用 Events / Format 解释 Dialogue；转通用模型丢字体、颜色、位置、样式和特效；绘图模式条目拒绝转换 |
| ASS 输出 | 统一基础样式，10 ms 精度并提示；过短条目、与控制语法冲突的正文会拒绝输出 |
| TXT | 输入须包含 SRT 风格时间行，不能从纯正文编造时间；输出纯正文会丢时间和编号 |

SRT / VTT 输出会重新解析验证。如果 CSV / ASS 正文包含内部空白段或类似时间头的文字，无法无损表达时拒绝输出，建议清理或使用 CSV 保留正文。

UTF-8、UTF-8 BOM、UTF-16 LE / BE 均有往返测试。UTF-16 输出带 BOM。无 BOM 的 UTF-16 推测为低置信度，需手动指定后再处理。GBK / GB18030 使用系统 WebView2 `TextDecoder`，经过固定字节测试，仅支持手动导入。无法确定编码时停止字幕输出，不自动降级为替代字符保存。

## 批量与导出

批量页对多个文件执行同一工具，顺序处理、单文件隔离。可取消正在运行的 Worker 和后续任务，重试失败 / 取消项。批量页不包含组合流程编辑器；多文件合并和双语合并在对应工具页使用。

输出为内存结果，确认后才写入。原生层只访问用户选取或拖入的路径，临时文件完整写入后以不覆盖方式发布；重名自动追加序号。ZIP 在打包前对大小写和 Unicode 等价名称去重，所有条目位于根目录。

浏览器版使用下载机制，不能选择桌面输出目录或打开 Explorer。浏览器下载发生后是否移动 / 删除文件由浏览器管理，历史只记录已请求下载的文件名。

## 处理前后差异预览

- 左右按逻辑字幕对齐，每页最多 20 行，可切换全部或仅变化。新增、删除、未匹配、重排及正文、时间、编号变化均有文字标记。
- 正文、时间和编号等属性可在同一行同时变化，摘要中的受影响行总数对每行只计一次。时间显示完整毫秒。
- 字符级高亮保留中文、emoji、组合字符和换行。超大文件或超长正文使用有提示的简化预览。合并显示输出概览，拆分按选定文件查看。TXT 与 JSON 以文本方式显示。
- 过滤、分页和切换输出只改变展示。修改输入、工具、参数或编码后，重新处理即可生成新的预览与导出结果。

## 命名参数预设

- 有参数的工具可保存、应用、更新、重命名或删除预设。更新、删除及清理损坏的预设需要确认，重置只恢复当前表单默认值。
- 每个工具独立列出自己的预设，同一工具内名称不区分大小写。名称最多 40 个可见字符，每个工具最多 20 项，全局最多 100 项，存储总量最多 256 KiB。
- 编辑表单后会提示已修改。应用会重新校验参数、填充表单并清除旧结果，用户随后自行启动处理。任务处理和导出期间，预设操作不可用。
- 只在确认保存时持久化工具参数。编码、目录、文件名规则、文件内容及授权均独立。损坏条目会隔离，无法读取的旧格式按实际情况提供重试或单独清理入口。

## 快捷键

| 快捷键 | 行为 |
| --- | --- |
| Ctrl + O | 选择文件 |
| Ctrl + Shift + O | 前往批量页并选择文件 |
| Ctrl + S | 导出当前结果，多文件导出 ZIP |
| Ctrl + F | 在有工具搜索 / 查找框的页面聚焦对应输入 |
| Esc | 关闭对话框；没有对话框时取消当前 Worker 处理 |

导出写入期间不提供强制取消，避免中断系统写入；界面会显示忙碌状态并阻止重复操作。
