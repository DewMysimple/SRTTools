# 功能与限制

当前应用版本为 0.4.0。工具列表只提供已经实现的功能；实际验收范围见 [TESTING](TESTING.md)，本轮本地候选与对外发布准备状态以 [收尾报告](RELEASE_CLOSURE_v0.4.0.md) 为准。

## 工作空间

- 五个主导航：首页、全部工具、批量处理、处理记录、设置。
- 工具按文本、合并拆分、格式、检测修复、时间、文件分类，支持名称和关键词搜索。
- 文件队列跨页面共用，允许排序、移除和清空；切换工具会清除该工具的临时预览结果。
- 文件导入、参数配置、只读预览与实际导出分开。处理失败保留输入和参数，写入失败保留结果。
- 设置和最近 200 次任务摘要保存在本机。预览和字幕全文不会写入历史。

## 可用工具

| 类别 | 功能 | 行为 |
| --- | --- | --- |
| 文本 | 查找替换 | 普通文字默认不区分大小写；可启用区分大小写和 Unicode 正则，校验非法表达式 |
| 文本 | 简繁转换 | OpenCC 通用简→繁 / 繁→简，只写正文，原编号、时间、换行和格式布局保留；支持预设与批量 |
| 文本 | 删除空白 | 删除只包含空白 / 不可见字符的条目 |
| 文本 | 空格清理 | 行首行尾去空格、合并连续水平空白，保留多行结构 |
| 文本 | 文本提取 | 输出 TXT，可保留或合并字幕内换行 |
| 文本 | 删除重复 | 仅连续重复或所有相同正文，保留首次出现的条目 |
| 文本 | 标点 / 大小写 | 常见中英文标点映射；英文大写、小写、单词首字母大写 |
| 文本 | 自动换行 / HTML 清理 | Unicode 字符计数、优先空格断行；移除标签、还原常见实体 |
| 合并 | 多文件合并 | 按文件顺序或开始时间排序，保留时间，重新编号 |
| 合并 | 双语合并 | 恰好两份文件，编号或开始时间容差匹配，上下顺序可交换；未匹配条目均保留并统计 |
| 拆分 | 按条数 / 时间 | 条数分组；时间点拆成两份，跨界字幕在两侧裁剪，默认保留绝对时间 |
| 对比 | 字幕对比 | 恰好两文件；共享逻辑对齐视图、差异摘要/筛选/分页，时间容差只影响已配对行时间分类；保留原列表位置诊断和无正文 JSON 报告 |
| 格式 | 格式转换 | 导入 SRT / VTT / CSV / ASS / SSA / 带时间 TXT；输出 SRT / VTT / CSV / ASS / TXT |
| 检测 | 字幕检测 | 结构、编号、非法 / 倒序 / 重叠时间、空白、重复、疑似乱码、每行超过 42 字符、时长小于 500 ms 或大于 10 s |
| 修复 | 重新编号 | 从 1 连续编号；普通标准字幕序列化也会连续编号，简繁原文写回保留编号 |
| 修复 | 检测与修复 | 重新编号、删除空白；无效时间保留 / 删除 / 延长至开始后 1 s；重叠保留 / 缩短前项，完成后重新检测 |
| 时间 | 偏移 | 整数毫秒，正延后、负提前；默认停止无效结果，可明确选择裁到零或删除无效条目 |
| 时间 | 显示时长 | 增减结束时间、设置最短 / 最长时长；默认拒绝无效时间，可能新增的重叠会提示 |
| 时间 | 范围裁剪 | 保留与范围相交条目，裁剪边界；完全无条目时拒绝空范围 |
| 文件 | 编码与换行 | 字幕规范化后导出为 UTF-8 / BOM、UTF-16 LE / BE、严格 GBK / GB18030，CRLF / LF |
| 文件 | 批量重命名导出 | 模板 `{name}` 与 `{index}`，生成新副本，不改原文件路径或名称 |
| 文件 | 信息与统计 | JSON 报告含格式、编码、条目、Unicode 字符数、跨度、诊断，不含字幕全文 |

大部分文本工具只改正文；删除工具会减少条目，普通导出默认重新编号。所有时间均使用整数毫秒。格式转换、编码和重命名导出会经统一模型重新序列化。简繁专门按现解析器确认的正文位置写回，并重解析验证条数、编号与时间：SRT、VTT、CSV、ASS、SSA 和带时间 TXT 的原布局保留，编码与命名仍按当前设置。保留标签、ASS 覆盖标记、占位符和原有多行；跨标记边界按分段词组转换，专有名词与歧义建议人工核对。不开未经质量验证的台湾/香港地区模式，不承诺简繁往返逐字可逆。

## 格式与编码

| 格式 | 输入要求与转换注意事项 |
| --- | --- |
| SRT | 容忍 BOM、CRLF / LF / CR、点号毫秒、缺失编号和额外空行；错误结构返回诊断，不能静默跳过后直接生成字幕 |
| VTT | 识别 WEBVTT 头、可选 cue 标识与设置；普通转换丢头部映射、位置、样式和区域信息并提示；简繁同格式写回保留 |
| CSV | 恰好 `index,start,end,text` 四列（顺序可调整），时间为 `HH:MM:SS,mmm`；逗号、引号、多行按 CSV 转义；额外列会拒绝，避免丢数据 |
| ASS / SSA | 使用 Events / Format 解释 Dialogue；普通转换丢字体、颜色、位置、样式和特效；简繁只写 Text，保留头、样式、注释与控制标记；绘图模式仍拒绝 |
| ASS 输出 | 统一基础样式，10 ms 精度并提示；过短条目、与控制语法冲突的正文会拒绝输出 |
| TXT | 输入须包含 SRT 风格时间行，不能从纯正文编造时间；文本提取输出丢时间和编号，简繁写回保留时间与编号 |

SRT / VTT 输出会重新解析验证。如果 CSV / ASS 正文包含内部空白段或类似时间头的文字，无法无损表达时拒绝输出，建议清理或使用 CSV 保留正文。

UTF-8、UTF-8 BOM、UTF-16 LE / BE 均有往返测试，UTF-16 输出带 BOM。无 BOM 的 UTF-16 推测为低置信度，需手动指定后再处理。GBK / GB18030 输入使用运行时 `TextDecoder` 且仍须手动选择；输出用固定版本 `@kayahr/text-encoding 2.2.0`，独立编码路径并逐段/整份严格往返核对。GBK `中文=D6D0CEC4`，GB18030 `😀=9439FC36`，GBK 无法表示 emoji 时定位条目与字符并拒绝。19 个无法逐字往返的 PUA 兼容映射也拒绝；支持范围是所验证的 WHATWG 映射，不声称所有 GB18030 版本或标准认证。源码回归遍历全部 Unicode 标量，覆盖 1,112,045 个可往返字符。无法确定输入编码时继续阻止字幕输出。

## 目录与 Explorer 导入

桌面“添加文件夹”默认不递归，可选择包含子目录和六种格式过滤。所有目录项最多 2,000、子目录最多 5 层；单文件 32 MiB、当前队列 100 文件 / 128 MiB。按可预测顺序追加，按真实原生路径去重，不仅按名称；不同目录的同名文件可共存。统计重复、不符格式、超限、读取失败、目录失败和跳过的链接/深目录。取消保留已加入项，未读完的一份不加入；后续可重试。浏览器模式隐藏入口，重启不保留目录读取授权。

Explorer 集成为实验性，默认关闭，设置中显式登记或禁用。仅写 HKCU 下六个扩展名的 `SRTTools.Import` 专属键，不改变默认文件关联，不启动 shell。Windows 11 传统菜单通常位于“显示更多选项”，Document 多选模型最多 15 文件。本轮机器的实际传统菜单未显示本项，显示/真实菜单点击导入为 BLOCKED，不能将登记成功宣称菜单已生效。官方单实例转发冷/热启动的具体路径，初始化且空闲后加入既有队列；参数、格式、reparse、读取权限和容量都受后端验证。移动程序后需显式修复到当前位置；禁用/卸载保护另一安装位置的键，更新保留已启用意图。程序路径含 `%` 时明确拒绝登记，避免占位解释。当前安装器仍无签名，环境覆盖见测试记录。

## 批量与导出

批量页提供“单项处理”和“处理流程”分段模式。都沿用逐文件、单 Worker 队列，失败隔离，可取消和重试失败 / 取消项。多文件合并、双语合并、拆分、独立对比与提取继续在对应工具页使用，不是逐文档流程步骤。

流程使用纵向步骤卡，支持添加、删除、上移/下移、启用/禁用、参数编辑和工具预设参数快照。白名单为删除空白、空格清理、查找替换、简繁、自动换行、HTML 清理、整体偏移、重新编号，最多20步。预执行检查按文件列出适用性，估计步骤/文件数和变化类型，不编造变化条数；真实执行后提供逐步摘要、文件/步骤诊断筛选和同一差异组件。

每文件一次输入解码/解析，在统一模型内顺序变换，末端一次序列化/编码及合法性复验。纯简繁流程保留原文布局；ASS/SSA/VTT 的其他组合默认拒绝，仅在弹窗明确同意后规范化为 SRT并提示样式/设置/控制标记损失。其他普通输出也会规范化编号，预览展示实际序列化编号。参数、步骤、文件或编码变化清除旧结果；切换模式保留未保存的流程草稿，但结果须重新执行。60秒文件超时停止并清理 Worker；取消可立即终止正在运行的 Worker，包括繁重正则。

批量页直接复用统一 ToolWorkspace 与同一个 `tool-presets-v1`，支持应用、保存和更新对应工具预设；无参数工具不显示入口。应用仅填参数，不执行、不改变文件与目录；改工具、参数、编码会清除旧预览和导出。处理与导出期间锁定，失败保参可重试。单文件与批量使用相同参数会产生相同字幕字节。

输出为内存结果，确认后才写入。原生层只访问用户选取或拖入的路径，临时文件完整写入后以不覆盖方式发布；重名自动追加序号。普通工具 ZIP 默认平铺；文件夹批量和流程可选择平铺或保留层级，目录与 ZIP 使用同一输出树预览。多输入根使用可见别名分组，根名冲突也避让；磁盘冲突后的实际路径会保留供后续 ZIP 使用。

目录输出先通过原生选择器授权独立目标并预览重名结果，再确认写入。源根与目标相同、互相包含均拒绝；拒绝绝对/UNC/盘符、`..`、链接/junction/reparse、保留名、尾点/空格和路径逃逸。危险源相对片段拒绝，合法但不便携的名称会规范化并标注；相对路径最多2048个UTF-16单元、10段，每段最多220单元，完整Windows路径最多32760单元。每次最多100输出/256MiB；单文件32MiB、队列100/128MiB不变。原子无覆盖，逐文件错误保留其余成功项；取消丢弃当前未发布文件，已发布项保留，重试只写未完成项。

浏览器版使用下载机制，不能选择桌面输出目录或打开 Explorer。浏览器下载发生后是否移动 / 删除文件由浏览器管理，历史只记录已请求下载的文件名。

## 处理前后差异预览

- 左右按逻辑字幕对齐，每页最多 20 行，可切换全部或仅变化。新增、删除、未匹配、重排及正文、时间、编号变化均有文字标记。
- 正文、时间和编号等属性可在同一行同时变化，摘要中的受影响行总数对每行只计一次。时间显示完整毫秒。
- 字符级高亮保留中文、emoji、组合字符和换行。超大文件或超长正文使用有提示的简化预览。合并显示输出概览，拆分按选定文件查看。TXT 与 JSON 以文本方式显示。
- 过滤、分页和切换输出只改变展示。修改输入、工具、参数或编码后，重新处理即可生成新的预览与导出结果。
- 独立“字幕对比”明确不信任跨文档 cue ID，左右显示第一份/第二份文件；逻辑摘要与 JSON 的 `visualComparison` 一致。旧按列表位置的诊断语义独立保留并标注，时间容差不重新定义匹配算法。解析错误或未确认编码只提供诊断报告，逻辑对齐暂不可用；合法空文件仍可表示真实增删。

## 命名参数预设

- 有参数的工具可保存、应用、更新、重命名或删除预设。更新、删除及清理损坏的预设需要确认，重置只恢复当前表单默认值。
- 每个工具独立列出自己的预设，同一工具内名称不区分大小写。名称最多 40 个可见字符，每个工具最多 20 项，全局最多 100 项，存储总量最多 256 KiB。
- 编辑表单后会提示已修改。应用会重新校验参数、填充表单并清除旧结果，用户随后自行启动处理。任务处理和导出期间，预设操作不可用。
- 只在确认保存时持久化工具参数。编码、目录、文件名规则、文件内容及授权均独立。损坏条目会隔离，无法读取的旧格式按实际情况提供重试或单独清理入口。

## 我的流程与预设交换

流程另存固定 `workflow-presets-v1` 键，最多50项（含隔离项）/512KiB；名称折叠空白，最多40个可见字符，描述最多1000字符。支持保存、更新、重命名、复制、确认删除，显示创建/更新时间与启用步骤数；空或全禁用草稿可保存但不能执行。失败保存保留编辑区；未知操作、未来版本和损坏项只读隔离、原配置保留，不自动执行或删除。旧 `tool-presets-v1` 键、旧合法预设、设置和历史兼容。

“导入/导出预设 JSON”与字幕输入分开。统一 `srttools-presets` v1文件最多1MiB/150项，UTF-8、缩进、固定字段排序；选中配置和个人查找/替换文字可分享，字幕、路径、授权、历史和凭据不进入文件。导出需明确选择并确认隐私提示；完整可执行样例见 [SRTTools-Presets.json](examples/SRTTools-Presets.json)。

导入先校验、显示兼容/冲突/跳过数量，再选择跳过、自动改名或明确确认覆盖；确认前不写存储，取消/错误不改旧值。外部ID重新生成，步骤ID保持流程内唯一；未知kind/操作/版本不执行。预览后存储改变则拒绝过期确认。工具/流程共享串行锁，浏览器支持同源Web Locks与原值恢复journal；桌面两键CAS在完整Store一次提交，失败恢复保全设置和历史。隔离冲突项不会在删除合法项后自动复活。

## 快捷键

| 快捷键 | 行为 |
| --- | --- |
| Ctrl + O | 选择文件 |
| Ctrl + Shift + O | 前往批量页并选择文件 |
| Ctrl + S | 导出当前结果，多文件导出 ZIP |
| Ctrl + F | 在有工具搜索 / 查找框的页面聚焦对应输入 |

普通单项另存为显示忙碌并阻止重复操作。新目录/层级 ZIP 导出可取消，目录写入在64KiB边界检查并在原子发布前确认；已完整发布文件保留。
